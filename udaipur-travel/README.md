# VaguePrompt - Udaipur Travel Website

A responsive travel guide website showcasing the beauty of Udaipur, Rajasthan — the City of Lakes.

## Features

- Hero section with Lake Pichola imagery
- About Udaipur with key facts
- 6 must-visit attractions (City Palace, Lake Pichola, Jag Mandir, and more)
- Photo gallery
- Best time to visit guide
- Essential travel tips for visitors

## Tech Stack

- React 18
- Vite 6
- CSS (Rajasthan-inspired design)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```
